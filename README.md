# QuickSpeech ABC  
Interaktivní webová aplikace pro učení amerického slangu podle tematických kategorií.  
Aplikace je navržena tak, aby byla jednoduchá, rychlá a dostupná i jako PWA.

---

## 🚀 Funkce aplikace
- Přehledné rozbalovací menu s desítkami témat.
- Dynamické načítání obsahu pomocí `<iframe>`.
- Moderní gradientový design.
- Podpora PWA (service worker + manifest.json).
- Offline režim pro základní strukturu aplikace.
- Každé téma má vlastní HTML stránku s frázemi.

---

## 🧩 Použité technologie
- **HTML5** – struktura a UI aplikace  
- **CSS3** – gradienty, layout, responzivita  
- **JavaScript** – logika přepínání témat  
- **PWA** – manifest + service worker  
- **Open Graph** – metadata pro sdílení
